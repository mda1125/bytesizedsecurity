{%- comment -%} Related Briefings — 3-card grid at post-bottom for next-click compounding. Placement (in _layouts/post.html): immediately AFTER the About-the-Author block and BEFORE Share This Article. The author bio establishes E-E-A-T; Related Briefings is the choice surface that converts that trust into a second pageview. Selection algorithm (pure Liquid, no plugin): hand-picked `related:` URLs first, then posts ranked by shared tags and category. See the comment above the selection code for details. Capped at 3 cards. Card markup mirrors the homepage Latest Intel card so readers re-use the same scan pattern, with a leaner byline (date + read time only — author is implied by the About-the-Author block directly above). Whole card is a single for one large Fitts's-Law-friendly click target. The section disappears entirely when no related posts exist (e.g., a single-post archive), so we never render an empty heading. {%- endcomment -%} {%- comment -%} Selection: 1. Posts listed in the page's optional `related:` front matter (URLs), in the order given. For hand-picking links on high-traffic pages. 2. Remaining slots go to the highest-scoring other posts. Each shared tag scores 2 (case-insensitive; "cybersecurity" is ignored because nearly every post has it), and the same category scores 1. Ties go to the newer post. With no overlap at all, this falls back to the newest posts, as the old category-only version did. Posts marked `noindex: true` are never recommended. Each candidate gets a sortable key "SS-TTTTTTTTTT|url" (zero-padded score, publish time in epoch seconds), so a plain string sort followed by reverse ranks by score and then recency. {%- endcomment -%} {%- assign page_tags = "|" -%} {%- for t in page.tags -%} {%- assign tl = t | downcase | strip -%} {%- unless tl == "cybersecurity" -%}{%- assign page_tags = page_tags | append: tl | append: "|" -%}{%- endunless -%} {%- endfor -%} {%- assign related = "" | split: "" -%} {%- assign picked_urls = "|" | append: page.url | append: "|" -%} {%- for url in page.related -%} {%- assign hit = site.posts | where: "url", url | first -%} {%- if hit and related.size < 3 -%} {%- assign related = related | push: hit -%} {%- assign picked_urls = picked_urls | append: hit.url | append: "|" -%} {%- endif -%} {%- endfor -%} {%- if related.size < 3 -%} {%- assign keys = "" | split: "" -%} {%- for p in site.posts -%} {%- assign url_marker = "|" | append: p.url | append: "|" -%} {%- if picked_urls contains url_marker or p.noindex -%}{%- continue -%}{%- endif -%} {%- assign score = 0 -%} {%- for t in p.tags -%} {%- assign tl = t | downcase | strip -%} {%- assign tag_marker = "|" | append: tl | append: "|" -%} {%- if page_tags contains tag_marker -%}{%- assign score = score | plus: 2 -%}{%- endif -%} {%- endfor -%} {%- if p.category == page.category -%}{%- assign score = score | plus: 1 -%}{%- endif -%} {%- assign padded = score | prepend: "00" | slice: -2, 2 -%} {%- assign epoch = p.date | date: "%s" -%} {%- assign key = padded | append: "-" | append: epoch | append: "|" | append: p.url -%} {%- assign keys = keys | push: key -%} {%- endfor -%} {%- assign keys = keys | sort | reverse -%} {%- assign needed = 3 | minus: related.size -%} {%- for key in keys limit: needed -%} {%- assign url = key | split: "|" | last -%} {%- assign hit = site.posts | where: "url", url | first -%} {%- assign related = related | push: hit -%} {%- endfor -%} {%- endif -%} {%- if related.size > 0 -%}
